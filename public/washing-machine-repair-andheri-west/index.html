Common repair enquiries

What has stopped working?

The same symptom can have different causes. An inspection is needed before the fault and repair cost can be confirmed.

01

Water not draining

Let us know if water remains in the drum, whether the pump runs and whether an error code appears.

02

Drum not spinning

Tell us if the machine fills and washes normally, and whether it makes an unusual noise.

03

Controls or motor fault

Panel errors, failure to start and new sounds help narrow down the checks needed during a visit.
